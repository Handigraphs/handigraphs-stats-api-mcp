## Notes for dependent shards

- Runtime configuration names/bounds are documented in AGENTS.md. HTTP is allowed
  only for explicit local-loopback tests outside production/Heroku runtime.
- The gateway exchanges every opaque MCP token at configured `/oauth/token` via
  `client_secret_basic`, RFC8693 access-token type and exact API audience/resource.
  It forwards only the returned short-lived API token to protected REST paths.
- Request-local SDK server/transport use JSON responses without session IDs.
  GET/DELETE authenticate and return 405; metadata and local health are public.
  Only public discovery cache/in-flight reads are shared; shutdown cancels that
  shared client's remaining I/O after drain.
- The nineteen business tools retain their local schemas/results. Local setup
  remains opt-in for stdio and is omitted from hosted. Backend research readiness
  is authoritative; PR-03 unavailable execution is preserved without fallback.
- `/health/ready` means validated local configuration/process readiness, not
  backend/worker/capacity or launch evidence. Real Codex/Claude Code acceptance
